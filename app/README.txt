QAMYAL — говори благое. Локальная запись и расшифровка разговоров

Запуск: ярлык «Qamyal» на рабочем столе (pythonw app.py, значок app\icon\qamyal.ico).
Иконка рисуется скриптом app\icon\make_icon.py (SVG → Chrome headless → Pillow → .ico);
он же обновляет app\web\icon.svg (значок окна и логотип). Папка D:\Расшифровка осталась прежней.
app.py поднимает локальный сервер (только 127.0.0.1) и открывает окно Chrome без адресной строки
(отдельный профиль в app\.ui-profile). Окно закрыли — сервер сам завершается через ~20 с
(если шла запись — она сохраняется и уходит в расшифровку). Второй запуск открывает ещё одно окно
к уже работающему серверу (адрес — в Записи\.server.json).

Разделы окна:
  Диктофон  — запись: «Разговор» (микрофон), «Созвон» (микрофон в левом канале + звук компьютера
              в правом), «Звук ПК». Пауза, ★ отметки (кнопка или клавиша M), живая расшифровка
              (GigaAM по кускам речи, отставание 5–20 с; фоновая обработка на это время на паузе).
              Запись пишется в Записи\.incoming\rec-*.flac; если программа упала — при следующем
              запуске такая запись восстанавливается и уходит в очередь.
  Записи    — карточки, поиск по тексту всех расшифровок, «спросить по всем записям» (Claude).
  Страница записи — плеер с волной и лентой говорящих, подсветка звучащей фразы, правка текста,
              переименование участника по щелчку на имени, краткое содержание, решения, задачи,
              кто сколько говорил, отметки, «спросить у записи», письмо участникам, протокол.
  Задачи    — задачи со всех встреч, галочки «сделано» (Записи\.tasks.json), фильтр «мои».
  Голоса    — запомненные голоса (Голоса\voices.json). Голос запоминается после каждой
              расшифровки, где имена известны; узнанные голоса подсказываются редактору.
  Словарь   — D:\Расшифровка\Словарь.txt: «Правильно (пояснение) — ошибка, ошибка».
  Настройки — имя, кто делает итог (Claude / локальная модель / без редактора), Whisper,
              микрофон, уведомления, «Claude видит записи (MCP)».

Claude и записи (MCP): mcp_server.py — Claude Desktop и Claude Code ищут в записях, читают расшифровки,
  смотрят, отмечают и добавляют задачи. Читает папку «Записи» сам, окно Qamyal не нужно; по stdin/stdout,
  без библиотек. Подключает кнопка в Настройках (claude_link.py): вписывает сервер в claude_desktop_config.json
  и выполняет «claude mcp add -s user qamyal»; если установлен Codex — вписывает [mcp_servers.qamyal]
  в ~/.codex/config.toml. Это обратное направление к «Кто делает итог»: там Qamyal зовёт ИИ, здесь ИИ — Qamyal.

Обработка (фоновый worker.py, пониженный приоритет, ноутбук не засыпает):
  подготовка → GigaAM → разметка голосов (sherpa-onnx) → узнавание голосов → Whisper turbo →
  редактура (claude -p) → оформление (Word и страница «ГГГГ-ММ-ДД Краткое название.docx/.html»,
  имена в черновики\файлы.json; при смене названия файлы переименовываются; волна, статистика) → уведомление.
Примерно 1,5–2 часа на час записи. «Свести итог заново» повторяет узнавание голосов и редактуру.

Модули: app.py (запуск), server.py (API), recorder.py + live.py (диктофон), worker.py, asr.py,
voices.py, editor.py, render.py, common.py; интерфейс — app\web (index.html, style.css, app.js).
Журналы: Записи\.worker.log, Записи\.app.log.
