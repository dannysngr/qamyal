# Qamyal

**Qamyal** («разговор» по-чеченски) — программа для записи и расшифровки рабочих разговоров: созвонов в Skype, Zoom, Телемосте и встреч вживую. Работает на Windows и macOS (Apple Silicon).

Что получается из записи:
- кто что сказал;
- краткое содержание;
- решения и задачи по проектам;
- письмо участникам или протокол.

По всем записям сразу можно задавать вопросы.

Распознавание идёт прямо на компьютере, звук никуда не уходит. Наружу, в редактуру, уходит только текст.

## Как это работает

1. **Запись:** микрофон, звук компьютера или оба канала сразу — в режиме «Созвон».
2. **GigaAM v3** (Сбер) — первый черновик: лучше всех понимает русскую речь.
3. **Whisper** (OpenAI, сборка faster-whisper) — второй, независимый черновик: английские слова, имена, термины.
4. **pyannote + WeSpeaker** (sherpa-onnx) — разметка голосов и узнавание знакомых людей.
5. **Редактура:** Claude Code сверяет два черновика слово за словом и пишет чистый текст, краткое содержание, решения и задачи. Вместо Claude можно выбрать Codex, локальную модель через Ollama или LM Studio, или работу без редактора.
6. **Итог:** Word и HTML в папке записи.

Две модели ошибаются в разных местах, поэтому сверка двух черновиков точнее любой из них.

## Устройство

| Папка | Что внутри |
|---|---|
| `app/` | программа на Python (общая для Windows и macOS): сервер `server.py`, диктофон `recorder.py` и `live.py`, обработка `worker.py`, распознавание `asr.py`, голоса `voices.py`, редактура `editor.py`, загрузка моделей `components.py`; всё, что зависит от системы, — в `sysdeps.py` |
| `app/web/` | интерфейс без сборки и внешних библиотек; языки — русский, English, нохчийн (`i18n-dict.js`) |
| `mac/` | оболочка окна и помощник записи звука на Swift, установка, сборка образа `.dmg` — см. [mac/README.md](mac/README.md) |
| `scripts/` | сравнение моделей распознавания |

Окно программы — локальная страница (`127.0.0.1`): в Windows — Chrome в режиме приложения, в macOS — своя оболочка на WebKit.

## Установка

- **macOS:** собрать образ `bash mac/build_dmg.sh`, перетащить Qamyal в «Программы» и открыть. Python и библиотеки приложение поставит само. Модели скачиваются кнопками в Настройках → «Модели и дополнения».
- **Windows:** Python 3.11, библиотеки из `mac/requirements-mac.txt` и `mac/requirements-speech.txt` плюс `winotify` (уведомления), GigaAM — из исходников. Запуск — `pythonw app/app.py`.
