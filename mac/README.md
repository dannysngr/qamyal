# Qamyal для macOS — передача работы

Для Claude на Mac Дэни (MacBook Air M2). Общение с Дэни — по-русски.
Подготовлено на Windows-компьютере 27.10.2026.

**Состояние на 27.10.2026, вечер.** Установлено на MacBook Air M2 (macOS 26.2) через SSH с Windows-компьютера.

Что проверено:
- `install.sh` проходит до конца;
- Swift собирается без ошибок;
- окно открывается;
- запись с микрофона работает;
- звук компьютера через tap работает;
- обработка целиком работает: 30 с записи — 53 с.

Исправлено по ходу:
- `soundcard` на Mac принимает буфер не больше 512, поэтому `blocksize=None`;
- `SO_REUSEADDR` в `pick_port`;
- живая расшифровка вынесена в отдельный процесс (`live.LiveProcess`): после записи он завершается и отдаёт системе около 1,9 ГБ.

Особенности этого Mac:
- 8 ГБ памяти и большая подкачка: живая расшифровка во время записи стоит около 1,9 ГБ;
- `claude` — старая npm-версия в `/usr/local/bin`; вход через `/login`;
- через SSH связка ключей недоступна, поэтому `claude -p` по SSH пишет «Not logged in». Из окна программы работает.

Ещё не проверено:
- ⌘C / ⌘V;
- перетаскивание файлов;
- `confirm` и `prompt`;
- закрытие окна во время записи.

## Что такое Qamyal

Программа Дэни для записи и расшифровки рабочих разговоров (русский, жаргон ННБ, созвоны ТОФС).
Порядок работы:
1. Диктофон или загруженный файл.
2. Два черновика: GigaAM (основной) и Whisper large-v3-turbo (английские слова и имена).
3. Разметка голосов sherpa-onnx и узнавание людей по отпечаткам голоса.
4. Редактура через Claude Code CLI по подписке: `claude -p …` из `editor.py`.
5. Итог в Word и HTML, задачи, проекты, чат с записью.

Записи — личные данные: они остаются на компьютере, их нельзя никуда публиковать.

Версия — «для меня и близких». **Без App Store и без аккаунта разработчика Apple.** Решение принято
после разбора: в песочнице App Store нельзя запускать Claude Code.

## Устройство Mac-версии

- **Python тот же, что в Windows.** Код в `app/` общий. Различия систем собраны в `app/sysdeps.py`:
  - процессы, «не засыпать» (`caffeinate`), уведомления (`osascript`);
  - `open` вместо `startfile`, поиск `claude` и `ffmpeg`.

  Остальной код систему не проверяет.
- **Окно** — `mac/QamyalApp.swift`, оболочка на AppKit + WKWebView, она же `Qamyal.app`. Порядок работы:
  1. запускает `~/Qamyal/.venv/bin/python app/app.py --no-window --parent <свой PID>`;
  2. ждёт `~/Qamyal/Записи/.server.json`;
  3. показывает `http://127.0.0.1:<порт>/` (порт обычно 47615).

  Python сам выходит, когда PID оболочки исчез. При выходе оболочка шлёт SIGINT, и идущая запись сохраняется.
  Фоновая обработка (`worker.py`) работает отдельно и переживает закрытие окна.
- **Звук компьютера** (режимы «Созвон» и «Звук ПК»):
  - `mac/QamyalAudioTap.swift` → `app/mac/QamyalAudioTap`;
  - Core Audio process tap, macOS 14.2+, пишет в stdout float32 моно 16 кГц;
  - в Python его читает `recorder.MacSystemAudio` с тем же интерфейсом, что у устройства soundcard;
  - разрешения в Info.plist оболочки: `NSAudioCaptureUsageDescription` («Запись системного звука») и `NSMicrophoneUsageDescription`.
- **Микрофон** — библиотека `soundcard`, как в Windows.
- **Подсказки Skype для бизнеса** (Lync SDK) есть только в Windows. На Mac сервис «Skype для бизнеса» — просто пометка, голоса определяются по звуку.
- **Установка** — `mac/install.sh`:
  1. проверка: arm64, macOS ≥ 14.2, Command Line Tools;
  2. копия программы в `~/Qamyal`;
  3. uv → Python 3.11 → `requirements-mac.txt` и GigaAM из `gigaam/`;
  4. модели (`download_models.py`): Whisper с Hugging Face, остальное привезено в комплекте;
  5. сборка двух Swift-модулей, иконка `.icns`, `Info.plist` с `QamyalRoot`;
  6. ad-hoc подпись, `~/Applications/Qamyal.app`.

## Установочный образ для других Mac (родные, близкие)

`Qamyal-ГГГГ.ММ.ДД.dmg`, меньше 1 МБ. Как у обычных программ (решение Дэни 28.10: «никаких чёрных окон»):
- в окне образа — `Qamyal.app` и ярлык «Программы»;
- фон рисует `mac/make_dmg_background.swift` прямо при сборке на Mac. Что на нём:
  - шрифт SF Pro Rounded и цвета значка;
  - заголовок «Перетащите — и готово»;
  - дуга из точек со стрелкой;
  - три шага;
  - подсказка про «Всё равно открыть».

  Обычная и Retina-версии склеены в TIFF;
- «Программы» — ярлык Finder (alias), а не символьная ссылка: у ссылки macOS 26 показывает пустой пунктирный квадрат.

Пользователь перетаскивает Qamyal и открывает его. Терминала он не видит.

- **Программа едет внутри приложения:** `Contents/Resources/payload` (код, исходники GigaAM, `QamyalAudioTap`) и `setup.sh`. Моделей и тяжёлых библиотек в образе нет.
- **Подготовка** (`mac/setup.sh`) — её запускает сама оболочка (`QamyalApp.swift`). Окно показывает логотип, полоску и шаги; при ошибке — текст и кнопку «Повторить». Запускается:
  - при первом запуске;
  - когда `CFBundleVersion` (дата и время сборки) отличается от `~/Qamyal/.installed-version`.

  Что делает:
  - копирует программу в `~/Qamyal` и снимает метку карантина;
  - качает `uv` (`UV_VERSION`), Python 3.11 и `requirements-mac.txt`: около 100 МБ, около минуты;
  - пишет `settings.json` с пустым `user_name` (`editor` = `claude`, если он уже есть).

  Журнал — `~/Qamyal/setup.log`.
- **Имя** при первом запуске спрашивает окно программы: приветствие `welcome()` в app.js, пока `user_name` пуст. Затем ведёт в Настройки к моделям.
- **Обновление:** перетащить новый Qamyal.app поверх старого. Настройки, записи и модели сохраняются.
- **Раскладка окна образа** делается через Finder (AppleScript) на временном томе `QamyalBuild<pid>`, иначе Finder путает его с открытым старым «Qamyal».
- Старый установщик через Терминал (`install.command`) — в `backups\mac-installer-terminal-2026-10-28`.

**Остальное пользователь качает сам кнопками** в Настройки → «Модели и дополнения» (`app/components.py`). Карточка видна всегда, потому что в ней выбирается Whisper:
- У каждой кнопки расписан состав: что скачивается, чьё, зачем, размер и откуда (`INFO[...]["parts"]`).
- «Распознавание речи и голосов», ≈ 720 МБ (GigaAM 449 + разметка 34 + библиотеки ≈ 230): `requirements-speech.txt`, GigaAM из `~/Qamyal/gigaam`, модель GigaAM с проверкой md5, разметка голосов. Пока его нет:
  - записи ждут в очереди (`spawn_worker` не запускает обработчик);
  - живая расшифровка выключена;
  - на «Записях» и «Диктофоне» висит подсказка.
- «Whisper» — на выбор (`WHISPER_MODELS`, репозитории и ревизии на huggingface.co закреплены):
  - large-v3, 3,1 ГБ;
  - large-v3-turbo, 1,6 ГБ, «рекомендуем», по умолчанию;
  - small, 486 МБ;
  - base, 148 МБ.

  Каждый вариант лежит в `models/whisper/<вариант>` (готовая папка, а не кэш HF); старые модели из кэша HF в Windows тоже считаются скачанными.
  - Выбранный вариант — `settings.whisper_model`. Скачанный вариант сразу становится выбранным, кнопка «Использовать» переключает варианты.
  - Невыбранный вариант можно удалить, только если он в своей папке.
  - Оценка «осталось ≈» учитывает скорость варианта (`speed`).
  - Варианты показаны таблицей «Вариант / Размер / Что это». Под ней строка «Ваш компьютер: модель, чип, память» (`sysdeps.machine_info`) и совет (`recommend_whisper`):
    - меньше 4 ГБ памяти — base;
    - меньше 6 ГБ — small;
    - 16 ГБ и больше при 10 и больше ядрах — large-v3;
    - иначе — large-v3-turbo.

    Советуемая строка подсвечена.
  - Если выбранный вариант не скачан, этап Whisper пропускается.
- «Claude Code»: открывает Терминал с установкой и входом. Когда `claude` появится, `editor` сам станет `claude` (флаг `claude_pending`).

Как идёт загрузка:
- отдельным процессом, переживает закрытие окна;
- ход — в `Записи/.components.json`;
- при обрыве докачивает с места (`.part`).

**Сборка на Mac Дэни:**
1. На Windows: `mac\make_kit.ps1`.
2. Скопировать `app/` и `mac/` в `~/Downloads/Qamyal-mac`.
3. На Mac: `bash ~/Downloads/Qamyal-mac/mac/build_dmg.sh ~/Downloads/Qamyal-mac ~/Desktop`.

**Проверено 28.10.2026** на чистой установке во временный HOME:
- `setup.sh` из образа со схемой «перетащить» — 59 с, приветствие с именем работает (окно Swift целиком не проверялось: по SSH нельзя увидеть экран);
- установка (прежним `install.command`) — 28 с;
- кнопка «Распознавание» поставила библиотеки и докачала разметку голосов;
- кнопка «Whisper» докачала файлы модели;
- запись голосом `say` прошла всю обработку: GigaAM, разметка, Whisper, оформление.

Скорость загрузки 800 МБ и 1,6 ГБ с нуля не проверялась: библиотеки брались из кэша uv, основные модели были подложены.

**Не проверено:** как именно выглядит предупреждение Gatekeeper при двойном щелчке на чужом Mac. У программы нет подписи Apple, поэтому нужно «Всё равно открыть» в настройках «Конфиденциальность и безопасность».

## Как ставить

1. Комплект собран на Windows (`mac/make_kit.ps1`, папка `-Out`). Перенести его на Mac можно через общую сетевую папку или флешкой.
2. Скопировать `Qamyal-mac` куда угодно, например в «Загрузки».
3. В Терминале выполнить: `bash ~/Downloads/Qamyal-mac/mac/install.sh`.

## Что проверить (всё — впервые)

1. **install.sh проходит до конца.** Возможные проблемы:
   - версии пакетов в `requirements-mac.txt` (torch 2.14.1 / torchaudio 2.11.0 / ctranslate2 4.8.3 под macOS arm64). Подберите ближайшие доступные;
   - `uv venv --allow-existing` в старой версии uv;
   - Whisper не скачивается с HF.
2. **Сборка Swift.** Код ни разу не компилировался:
   - `QamyalAudioTap.swift`: CATapDescription, aggregate device, AVAudioConverter;
   - `QamyalApp.swift`.
   Ошибки компиляции чинить по месту.
3. **Окно открывается.** Проверить:
   - страница загружается, тёмная тема;
   - ⌘C / ⌘V в полях;
   - перетаскивание файлов в окно;
   - кнопка «Загрузить готовую запись» (панель открытия файла);
   - `confirm` и `prompt` (удаление записи, переименование голоса);
   - звук плеера и перемотка.
4. **Запись:**
   - «Разговор» (микрофон, разрешение);
   - «Созвон» и «Звук ПК» (разрешение «Запись системного звука»; включить видео с YouTube и убедиться, что правый канал не пустой);
   - живая расшифровка.
5. **Обработка записи целиком:**
   - GigaAM, Whisper, разметка;
   - редактура через `claude` (`which claude`; путь ищет `sysdeps.find_program`);
   - Word и HTML открываются (`open`);
   - уведомление.

   Скорость сравнить с Windows: на i5-4300U 31 минута записи — около 50 мин обработки. На M2 должно быть заметно быстрее. Число потоков — `default_threads()`, 4.
6. **Закрытие окна во время записи:** запись должна сохраниться и уйти в расшифровку.

Если tap не заработает, запасной путь — ScreenCaptureKit (`SCStream` с `capturesAudio`). Его минус: нужно разрешение «Запись экрана».

## Правила

- **Код общий для обеих систем.** Всё, что зависит от системы, — только в `sysdeps.py` или в `mac/`. Windows-версию не ломать: там ею пользуются каждый день.
- **Основная копия — на Windows-компьютере.** Изменения, сделанные на Mac, нужно вернуть туда (`app/`, `mac/`) и сказать Дэни, какие файлы поменялись.
- Новые надписи интерфейса добавлять в `app/web/i18n-dict.js` (русский / English / нохчийн).
- Решения Дэни не переспрашивать. Письма по итогам созвонов — только сказанное, без своих предложений.
